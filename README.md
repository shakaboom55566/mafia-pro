# Mafia Pro

Приложение ведущего для живой игры в мафию — Telegram Mini App. Один HTML-файл, без сервера: роли, 2D-иллюстрации карт, 3D-карта с рубашкой, ночь/день/голосование по правилам, разбор партии, профили и рейтинги, магазин. Пять языков: русский (по умолчанию), украинский, английский, польский, армянский.

**Приложение:** https://shakaboom55566.github.io/mafia-pro/

## Режимы

- **Классическая (спортивная) мафия на 10** — Дон, 2 мафии, Шериф, 6 мирных. Международные правила: речи 60 с, выставление, голосование, оправдательные речи, переголосование, подъём всех, последняя речь и лучший ход, фолы.
- **Расширенная игра 7–24 игрока** — 55 карт (31 базовая, 12 премиум, 12 из пака «Дипломатическая игра»), с 20 игроков две семьи, редактор состава с индикатором баланса. Ночь 0, пошаговые пробуждения, утро, голосование с весами голосов; ничья → оправдания → переголосование → рулетка 1–9.
- **Разбор партии** — кто ошибся и что было бы лучше, очки «пользы» входят в рейтинг.

## Публикация как Telegram Mini App

Приложение уже выложено на GitHub Pages по адресу выше. Привязка к боту делается в [@BotFather](https://t.me/BotFather):

1. `/newbot` → имя **Mafia Pro**, username вида `mafiapro_bot`. Сохранить токен.
2. `/newapp` → выбрать бота → название **Mafia Pro** → описание → картинка 640×360 → **Web App URL:** `https://shakaboom55566.github.io/mafia-pro/` → короткое имя `app`.
   Ссылка на приложение: `https://t.me/mafiapro_bot/app`
3. `/mybots` → бот → **Bot Settings → Menu Button** → тот же URL, чтобы приложение открывалось кнопкой в чате.
4. `/setuserpic`, `/setdescription`, `/setabouttext` — иконка и описание.

### Глубокие ссылки для рекламы

| Ссылка | Что открывает |
| --- | --- |
| `t.me/mafiapro_bot/app?startapp=classic` | сразу стол классической мафии на 10 |
| `?startapp=shop` | магазин |
| `?startapp=cards` | все карты |
| `?startapp=card_<id>` | карта роли (`don`, `sheriff`, `kamikaze`, `sapper`, …) |
| `?startapp=scen_<id>` | сценарий (`summit`, `bought_votes`, `quiet_revolution`, `big_politics`, …) |

### Что встроено для Telegram

Автораскрытие на весь экран, цвета шапки и фона, запрет закрытия свайпом (иначе не покрутить 3D-карту), родная кнопка «Назад», подтверждение закрытия во время партии, вибрация на раздаче/выстреле/голосовании, профиль «я» из аккаунта Telegram, язык интерфейса из языка Telegram. Вне Telegram приложение работает как обычная страница.

### Бэкенд (следующий этап)

Покупки за Telegram Stars, общие рейтинги между телефонами и раздача карт игрокам в личку требуют сервера с токеном бота. Приложение уже умеет его вызывать: если задать `window.MAFIA_API = 'https://ваш-сервер'`, кнопка «Купить» делает `POST /invoice` `{kind, id, initData}` и открывает полученный счёт через `openInvoice`.

## Разработка

```
bash build.sh          # собирает index.html (+ deploy/, mafia-pro.html для тестов)
node test/sim.js       # симуляция движка
node test/ui-smoke.js  # прогон всех экранов без браузера (LANG_CODE=uk|en|pl|hy)
node test/browser-qa.js  # Chromium, размер iPhone (нужен npm i playwright)
node test/montecarlo.js  # баланс ролей
```

Структура:

```
src/
  01-head.html            разметка и CSS
  02-i18n.js … 02n-*.js   переводы (ru/uk/en/pl/hy), тексты ролей, сценариев, контрпиков
  02f-icons.js            SVG-арт карт и рубашка
  02-data.js              роли, порядок ночи, сценарии, паки, контрпики, цены
  03-engine.js            движок: ночь, день, голосование, эффекты, победа
  04-ui.js                экраны и действия
  05-profiles.js          профили, рейтинги, 3D-карта
  07-review.js            разбор партии
  08-telegram.js          интеграция с Telegram Mini App
  06-shop.js              магазин
test/                     симуляторы и тесты
.github/workflows/        автопубликация на GitHub Pages при пуше в main
```

Деплой автоматический: любой пуш в `main` пересобирает и публикует сайт (Settings → Pages → Source: GitHub Actions). Запасной вариант без Actions — Source: Deploy from a branch, `main` / `(root)`: в корне лежит готовый `index.html`.
